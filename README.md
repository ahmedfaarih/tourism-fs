# Maldives Tourism Forecasting — Modeling Repo

A self-contained snapshot of the demand-side forecasting work for the thesis *An Automated
Data Pipeline and Forecasting Model for Maldives Tourism Statistics* (Business Informatics
MSc, Corvinus University of Budapest).

## Contents

- `raw_data/` — extracted Ministry of Tourism monthly statistics (`tourism_dataset_extracted/`)
  and supplementary Maldives Central Bank / weather series (`supplementary_data/`), already
  parsed into JSON. Nothing here is hand-edited.
- `code/`
  - `clean_tourism_dataset.py` — merges all raw sources into one tidy monthly dataset,
    applying documented data-quality fixes without altering the raw files.
  - `model_baseline_demand.py` — the demand-side forecasting baseline: ADF stationarity
    testing, log-transformed arrivals, monthly seasonal dummies, flight-movement and
    exchange-rate regressors, ARIMA order selection, and evaluation against a seasonal-naive
    benchmark.
- `model_outputs/` — everything generated by the scripts above: the merged dataset, the
  forecast chart, and the evaluation metrics. Nothing here is hand-edited; rerun the scripts
  to regenerate.

## Running it

```
cd code
python3 clean_tourism_dataset.py     # rebuilds model_outputs/tourism_model_dataset.csv
python3 model_baseline_demand.py     # fits the model, evaluates it, writes the forecast chart
```

## Current status

This is a first-pass demand-only baseline, not a finished model. On the most recent 12-month
holdout it does **not** outperform a simple seasonal-naive forecast (21.6% vs. 12.1% MAPE) —
a diagnostic finding, not a hidden failure. The next planned step is a supply-side augmented
version (adding accommodation/bed capacity) to test whether that improves on this baseline,
which is the thesis's actual research question.
